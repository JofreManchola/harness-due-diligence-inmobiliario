# Fuentes de verificación

Muchas de estas consultas tienen captcha o requieren datos personales: los agentes **no** las dan por verificadas; dejan el paso exacto en `pendientes.md` para que el comprador (o su abogado) lo haga.

## Inmueble
| Qué | Dónde | Nota |
|---|---|---|
| Autenticidad del certificado de tradición | certificados.supernotariado.gov.co (verificar con el PIN del certificado) | Gratis |
| Certificado de tradición nuevo | certificados.supernotariado.gov.co / ORIP | ≈ $20–25 mil |
| Consulta VUR (Ventanilla Única de Registro) | vur.gov.co | Requiere usuario (notarías, abogados) |
| Datos catastrales, avalúo, área, estrato, uso | Catastro Bogotá — catastrobogota.gov.co (Certificado catastral gratuito, Mapas Bogotá) | CHIP del predio |
| Norma urbana, tratamiento, amenazas | mapas.bogota.gov.co / SINUPOT (Secretaría Distrital de Planeación) | Por dirección o CHIP |
| Amenaza por remoción en masa / inundación / sísmica | IDIGER — idiger.gov.co, Mapas Bogotá capa “Amenazas” | |
| Estado de cuenta predial | Secretaría Distrital de Hacienda — haciendabogota.gov.co (Oficina virtual) | CHIP |
| Valorización | IDU — idu.gov.co (Certificado de estado de cuenta para trámite notarial) | CHIP |
| Plusvalía | SDP / Catastro (consulta de participación en plusvalía) | |
| Licencias de construcción del proyecto | Curadurías urbanas de Bogotá (consulta por dirección), SDP | |
| Constructora / pólizas | RUES (rues.org.co) para la sociedad constructora; Superintendencia de Sociedades | |

## Personas (vendedores, apoderados, intermediarios)
| Qué | Dónde |
|---|---|
| Vigencia de la cédula (y que la persona no figure fallecida) | Registraduría — wsp.registraduria.gov.co/certificado |
| Antecedentes disciplinarios | Procuraduría — procuraduria.gov.co (certificado de antecedentes) |
| Responsabilidad fiscal | Contraloría — contraloria.gov.co |
| Antecedentes judiciales | Policía Nacional — antecedentes.policia.gov.co |
| Medidas correctivas (Código de Policía) | srvcnpc.policia.gov.co |
| Procesos judiciales (embargos, ejecutivos, familia) | Rama Judicial — consultaprocesos.ramajudicial.gov.co (por nombre/razón social) |
| Listas restrictivas internacionales | OFAC SDN (sanctionssearch.ofac.treas.gov), Consejo de Seguridad ONU |
| Inmobiliaria / corredor | RUES, Lonja de Propiedad Raíz de Bogotá, Fedelonjas |
| Avaluador | Registro Abierto de Avaluadores — raa.org.co (Ley 1673 de 2013) |
